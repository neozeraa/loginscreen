# 🚀 Login Screen - VERY SYSTEMS

Uma tela de login e cadastro moderna, responsiva e pronta para uso em novos projetos.

**O que este repositório traz:**
* Interface completa com abas de "Entrar", "Criar Conta" e "Recuperar Senha".
* Proteção de senha simulada (hash em PBKDF2) utilizando localStorage.
* Design adaptável com suporte automático a Tema Claro e Escuro.
* Ferramentas de linha de comando (empresa e teste) para agilizar a edição.

**Como Instalar**
git clone https://github.com/neozeraa/loginscreen.git
cd loginscreen

**Comandos do Terminal**
**1. Personalizar a Marca**
Altera instantaneamente o nome da empresa na tela.
* Uso: ./empresa [NOME_DESEJADO]
* Exemplo: ./empresa NOVADEV

**2. Visualizar o Projeto**
Sobe um servidor local para testar a interface.
* Uso: ./teste
* Como acessar: http://localhost:8080
